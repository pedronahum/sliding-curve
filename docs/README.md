# Documentation

The library's own documentation is the package docstrings and the README at
the repository root. The pages here are the record of the replication of
Piterbarg & Van Der Helm (2026) that this library was built against:

- [paper_results.md](paper_results.md) — the library against the paper's
  plotted and printed numbers, section by section, with the figures.
- [investigation.md](investigation.md) — the log of every issue found while
  replicating the paper: its status, the evidence, and the variants tried.
  Every item is closed.
- [questions_for_authors.md](questions_for_authors.md) — the record of what
  was put to the paper's authors and their answer.
- [investigation/](investigation/) — overlays of the digitised points on the
  paper's figure axes: the digitisation check.

`../examples/` holds the runnable demonstrations referenced by
`paper_results.md`; `../experiments/` holds the scripts behind
`investigation.md`.
